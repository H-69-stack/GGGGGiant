# 24TK_1324-2 管件形线 / 壁厚分析失败总结

## 一、任务概述

- **分析对象**：24TK_1324-2.stp（弯管，末端带扩口）
- **分析目标**：中心形线、轴向壁厚线、完整周向壁厚场 t(s, θ)、精确外周长，并执行独立 QA 验收
- **使用工具**：CAD 管件形线与壁厚分析插件（确定性几何引擎 + 独立验证器），对 STEP 名义几何进行解析

## 二、失败现象

- **错误码**：`NON_MONOTONIC_TOPOLOGY`（拓扑非单调）
- **错误信息**：弦轴扫描发现有效截面带分离 `[[1,143],[145,159]]`，管件非单次穿越
- **可复现性**：预检（inspect）与正式分析（analyze）结果一致，错误稳定复现，非偶发采样问题

## 三、失败原因

### 1. 算法机制（背景）

插件沿两端端面中心的连线（弦方向）均匀布置 161 个法向截面，逐刀切取截面轮廓。每个截面必须恰好得到一个外环 + 一个内环的"星形"环形截面，壁厚才有唯一数学定义（外环点沿内法线到内环的首个交点距离）。

### 2. 直接触发点

扫描结果中，索引 **144**（弦向约 90% 处）的截面无效：该平面切出的闭合环数量不是 2 个（内环退化或内外环无法配对），被判定为不可用截面。有效截面带因此断裂为 [1,143] 与 [145,159] 两段，引擎判定拓扑非单调，整体终止。

### 3. 根因分析

管件结构为**弯管 + 末端扩口**，与算法前提冲突：

- **弯管**：端点连线（弦）不沿真实轴线，弯段处法平面切出的截面偏离标准环形。引擎对此有迭代补偿设计（理论上支持弯管），但前提是扫描阶段能先获得足够的连续有效截面；
- **末端扩口**：扩口段为锥形喇叭，管壁倾斜。在扩口过渡区，法平面斜切锥面，截面出现内环退化、轮廓非星形等问题，壁厚无法定义；
- 索引 144 恰好落在**扩口过渡临界截面**，同时触发上述问题，导致扫描中断。

### 4. 工具设计特性（为何无部分结果）

该工具采用 fail-closed 设计：任一截面不合格即全盘不输出任何数据文件，包括已扫描成功的 158 个有效截面的数据。目的为避免产出"半真半假"的数据误导下游工艺判断。

## 四、结论与后续方案

- 当前模型在此工具下**不可分析**，且无合规绕过路径（禁止修改判定阈值、禁止用相邻截面插值补洞，二者都会产生虚假数据）；
- **后续方案**：在 CAD 中将扩口段切除，或在扩口过渡处将管件切分为"主管段 + 扩口段"两个实体，使每段均为两个平面环形端面的单一实体，再重新分析；
- **结果声明**：分析结果为 CAD 名义壁厚，不等于制造后实测壁厚。

## 五、经验教训

1. 工具适用边界明确：单一实体、毫米单位、完整内外壁、两个环形平面端面、沿轴向单调穿越、截面为星形环形。**弯管可支持，但非星形截面（扩口、压扁、开孔、凸台、多腔、分叉）不支持**；
2. 分析前应先核对管件结构是否含扩口/压扁等特征段，若含此类特征，需先做模型分段预处理，避免分析中途失败；
3. 遇到 fail-closed 工具的报错，应优先理解其判定机制，而不是尝试绕过；对结果完整性要求高的场景，全盘失败优于部分数据。
