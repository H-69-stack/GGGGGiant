# GIANT 合并版本使用说明

本说明适用于 GitHub `main` 的 `65e0b3e` 与本地原生 STP / 模具修复合并后的源码。原有安装版 EXE 没有重新打包。四个工序的详细参数还可参考 [原模具使用说明](软件使用说明_2026-09-21.md)；读取与 QA 操作以本文件为准。

## 启动

在项目根目录执行最新版提供的 `dev.ps1`。Python 环境必须包含 `backend/requirements.txt` 中的依赖，特别是 `cadquery-ocp`。本机本次验证使用的解释器是项目原目录下 `.venv-stp-validation/Scripts/python.exe`，可通过 `GTAPP_PYTHON` 指定：

```powershell
$env:GTAPP_PYTHON = Join-Path $PWD '.venv-stp-validation/Scripts/python.exe'
.\dev.ps1
```

该启动器使用后端 5050 和前端 3000；如已有程序占用端口，按启动器提示处理，不要同时启动两个实例。项目正式登录与授权逻辑保持原样。本次回归的隔离测试入口是 5058 / 3018，使用独立数据库，不是生产数据库。

## 读取与保存管件

1. 打开模型读取页面，导入原 STP/STEP，选择算法并等待完成。复杂管件的原生 CAD 截面计算可能需要数分钟至数十分钟。
2. 查看三维模型上的中心线、截面曲线和周长/壁厚曲线。中心线指法向截面外轮廓的面积质心轨迹；非圆截面等效直径为周长除以 π，不是截面最大宽度。
3. 先看“STP 原生截面测量”的提示。有缺测或法向待复核截面时，不能直接进入工艺优化或模具生成。端部未形成完整内外双闭环的区域不外推，显示的是有效测量长。
4. 按新版界面确认壁厚分段与图纸长度，完成长度校验、必要的端部长度分配和关键截面校验。
5. 在形线质量检查中处理实际异常、确认直管段，明确选择自动形线或人工测量形线，再保存管件。形线 QA 通过不等于三维截面法向已通过校核。
6. 进入工艺规划，确认对应工艺阶段与约束参数，运行优化并保存工艺设计。新版 `Dn`、`D2` 参数传递和约束已保留。

手工修改周长、壁厚、长度或选择人工形线，影响的是工艺数据；原始 `sections_full` 的内外轮廓、位置、法向和局部坐标仍保留，供成型使用。原生截面的主方向长宽用于关键截面比对，不自动代表已经确认的压扁椭圆轴长。

旧记录如果只有 STL 截面或周长，没有原生内外轮廓，需要重新读取 STP、重新保存管件和关联工艺设计。打开旧记录不会自动重建缺失的 CAD 几何。

## 硬模成型和反切

1. 进入“硬模成型 → 加载数据”，加载刚保存的工艺设计。
2. 根据工序选择扩口、压扁、压弯或成型。
3. 四个页面均有“生成反切实体模具”开关，默认关闭。
4. 开关关闭时，保留原输出：扩口芯轴/腔体、压扁模型、压弯模型，或成型外径腔体/实心内径。成型直接使用读取的真实内外轮廓。
5. 开关开启时，程序使用外径实心腔体反切长方体。先保留“自动推荐外形尺寸”，单侧余量默认 15 mm。生成后显示 XYZ 模坯尺寸；也可以输入足以包围腔体的自定义尺寸。
6. 生成后切换完整外观与剖视，检查内部造型，再保存/下载 STEP。修改参数后必须重新生成，旧模型不能作为新参数结果下载。

自动尺寸是腔体在当前模型 XYZ 坐标下的包围盒，加上两侧余量，向上取整到 0.1 mm。剖视只改变显示，STEP 仍保留完整 CAD 实体。

当前反切输出是**封闭型腔的整体模坯**。分模面、上下模拆分、定位件、排气与工艺补偿仍需工程师设计；不要把该输出理解为可直接装机的完整模具总成。

扩口使用等周长圆截面；压扁使用前序确认的椭圆完整轴长；压弯把同一组截面布置到目标中心线上；成型直接使用原始非圆截面。压扁轴长与周长不相容或缺失时，必须先修正输入，程序不会猜测短轴。

## TP 抽套模

1. 在 TP 页面选择从工艺设计数据库加载，选择对应工艺设计。
2. 检查大端内径 `T_D`、小端内径 `D`、TP 段长 `T_L` 及两个原始站位。使用 TP 工艺的前序结果，不能拿任意工序的参数代替。
3. 型线表的 X 为轴向坐标、Y 为直径。程序按端点站位裁取真实型线，统一大小端方向，再与固定外形闭合并旋转 360°。
4. 点击“生成套模”，检查完整外观和下载的 STEP。

沿用的固定外形：主体外径 95 mm，法兰外径 125 mm，法兰厚度 8 mm，总长 `T_L + 27 mm`。型腔任何位置的直径必须小于 95 mm；更大规格需要另行设计外形模板。

如果大小径没有匹配到测量型线、段长不相符或管件有缺测/法向问题，系统会给出明确错误。不要通过改小校验阈值或替换成猜测圆管绕过。
