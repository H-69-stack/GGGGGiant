## 4. 冻结接口

### 4.1 `core/entity/route_prefs.py`（A2）

持久化文件：`entity_out/_config/route_prefs.json`（由 `settings.OUT_ROOT` 派生）。结构：

```json
{
  "version": 1,
  "parts": {
    "H0A3Z2-DT": {
      "direction": "auto",
      "models": {
        "成型_外径形腔": {"impl": "121", "direction": "auto"}
      }
    }
  }
}
```

函数：

```python
PREF_FILENAME = "route_prefs.json"
def prefs_path(out_root=None) -> Path
def load_prefs(path=None) -> dict            # 容错：文件缺失/损坏返回 {"version":1,"parts":{}}
def save_prefs(prefs: dict, path=None) -> dict
def get_part_pref(prefs, part) -> dict       # {"direction": "auto", "models": {...}}
def get_model_pref(prefs, part, key) -> dict # {"impl": "default"|"c1"|"121", "direction": "auto"|"X"|"Y"|"Z"}
def set_model_pref(prefs, part, key, *, impl=None, direction=None) -> dict
def resolve_impl(prefs, part, key) -> str    # "c1" | "121"；缺省回落到 contracts.uses_reference_route（2052 外径形腔=121）
def resolve_direction(prefs, part, key) -> str  # "auto"|"X"|"Y"|"Z"
```

### 4.2 `contracts.py`（A2）

- `uses_reference_route(part, key, prefs=None) -> bool`
- `end_treatment_for(part, key=None, prefs=None) -> "c1"|"v1"`（121 → v1）
- `ModelSpec` 增加字段 `direction: str = "auto"`（默认值保持兼容；位置参数顺序不要变，加在末尾）
- 其余常量/函数保持原签名可用。

### 4.3 `orchestrator.py`（A2）

- `build_specs(parts, models, routes, out_root, prefs=None)`：按件/模型解析 impl 与 direction；121 时 `end_treatment="v1"`、`reference_step=源 STEP`。
- `run(ctx)`：从 `ctx.options.get("route_prefs")` 取 prefs；没有则 `route_prefs.load_prefs()`；把 `spec.direction` 传下去。
- `_part_models`：优先 `prepare_proc.run_prepare(...)`（子进程，可杀）；导入/运行失败回落原逻辑。
- 停止检查点统一走 `_stop_at(ctx, stage, part, key)`，每个单元前后都查 `ctx.options["stop_event"]`。

### 4.4 `core/entity/proc_control.py`（A1）

```python
def register(proc, label: str) -> None
```

### 4.5 `core/entity/prepare_proc.py`（A1）

```python
class PrepareCancelled(RuntimeError): ...
class PrepareFailed(RuntimeError): ...
def run_prepare(*, part, step, end_treatment, out_root, models=None, force=False,
                log=print, stop_event=None, timeout=7200.0) -> dict
# 返回 {"models": {key: step_path}, "measured_path": str, "seconds": float, "cached": bool}
```

实现：写 job json 到 `out_root/_scratch/prepare_jobs/job_<uuid>.json` → `subprocess.Popen([sys.executable, "-m", "core.entity.prepare_worker", job_json], cwd=backend, env=..., stdout=PIPE, stderr=STDOUT, text=True)` → 注册到 proc_control → 逐行读 stdout 转 log → 轮询 stop_event（0.2 s）→ 停止时 `terminate_tree(pid)` 并抛 `PrepareCancelled`。子进程退出码非 0 或 result json 缺失 → `PrepareFailed(最后 20 行输出)`。

`prepare_worker.py`：读 job json → `giant_adapter.measure(...)`（命中缓存则快）→ `giant_adapter.export_models(...)` → 写 `<job>.result.json` → 退出 0。所有异常打印 traceback 并退出 1。

### 4.7 HTTP API（A4）

新增/修改（全部在 `url_prefix="/api/entity"` 下）：

- `GET  /parts/<part>/route-pref` → `{"part":..,"model":"成型_外径形腔","impl":"c1","direction":"auto","effective":{"impl":"c1","end_treatment":"c1"},"impls":["c1","121"],"directions":["auto","X","Y","Z"]}`
- `POST /parts/<part>/route-pref` body `{"model":"成型_外径形腔","impl":"121","direction":"auto"}` → `{"ok":true,"route_pref":{...},"plan":{...}}`；`impl` 接受 `c1|121`（大小写不敏感），非法值 400。

- `GET  /uploads` → `{"tasks":[{task_id,part,status,progress,message,created_at,error}]}`
- `GET  /uploads/<task_id>` → 单条。
- `POST /stop` body `{"mode":"graceful"|"force"}`（缺省 graceful）：
  - graceful：置 `stop_event`，状态 `stopping`，返回 `{"ok":true,"mode":"graceful"}`；
  - force：置 event + `proc_control.terminate_all()` + 立即把 job 标 `stopped`，返回 `{"ok":true,"mode":"force","killed":[labels]}`。

- `POST /run` 的 body 允许 `{"parts":[...],"models":[...],"routes":{...},"force":false,"route_prefs":{...}}`；服务端合并磁盘 prefs。
- `GET /parts` 递归包含 `gnt管件/uploads/` 下的 STEP；返回项带 `source: "builtin"|"upload"`。

`app.py` 只加：`from api.entity_upload import bp as entity_upload_bp` 与 `app.register_blueprint(entity_upload_bp)`（如需拆文件）；否则不改。

## 附：分型方向 A 方案落地（2026-11-06 晚）

- **自动（A 方案）**：截面质心 PCA 判定平面弯（`s1/s0 > 1e-4` 且 `s2/s0 <= 5e-3`）时，分型方向取
  **弯曲平面法向 n**（`directions.planar_bend_normal`），`rule="bend_plane"`；直管/空间弯回退三轴评分。
  增加「截面环是按弧长排序的闭合轮廓」校验，随机散点云不会被误判成平面弯。
- **手动角度兜底**：`angle:<deg>` 表示绕 +Z、从 +X 逆时针的角度；流程页「方向 → 手动角度（绕 Z）」+
  角度输入框（默认 −27）即此路径，落库规范为 `angle:%g`。
- **判据**：缝点必须是截面沿 ±n 的**支撑点**（`seam_u / ring_umax = 1`），不是「缝到弯曲平面距离≈0」
  （缝在 ±n 极点，距平面约等于半径）。
- **验收结果**：H0A3Z2 v1+121 auto → n=(0.8918, −0.4525, 0)，4 面/1 实体/2 分型边/0 自由边/valid，
  体积 1,024,836.2 mm³（+0.083%）；手填 −27° 得到同一方向（rule=selfref/manual）；2052 auto → ±Y，
  135,077.6 mm³（−0.017%），与旧基线一致。
